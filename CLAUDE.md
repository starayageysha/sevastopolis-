# Севастополис 3D — правила для Claude Code

Это существующая игра Светланы Якимовой. Её развивают, а не пишут заново. Общаемся по-русски, коротко объясняем, почему принято то или иное техническое решение.

## Обязательно
- Ничего не удалять и не упрощать без прямой просьбы: героя-лисёнка, NPC и менеджер жителей, лассо, весь транспорт (суша, вода, вертолёт), посадку и высадку, физику, районы, Парк Победы, набережную, море, свет, звуки, магазин, настройки.
- Море не упрощать. Мелкие объекты ради скорости не объединять и не удалять.
- `backups/` не трогать.
- Не заявлять об ускорении без замеров (`tools/test/bench.py`, `tools/test/cpuprof.py`). Не выдумывать результаты тестов.
- Перед коммитом запустить `npm run dev` и `npm run test`: сцены должны строиться, а в консоли не должно быть ошибок.
- Одна версия — один коммит: `vNNN — что сделано`. Рабочую ветку `main` обновлять только проверенной версией.
- Игру не публиковать и видимость репозитория не менять без разрешения автора.
- Автор тестирует на Pixel 7: после каждого шага давать ей файл или ссылку для проверки.

## Устройство
- `index.html` подключает модули по порядку. Ядро `src/core/game.bundle.js` (Vite-бандл с Babylon.js 9.32) — модуль ES, он выполняется после разбора страницы. Дополнения `src/addons/*.js` — обычные скрипты, ищут игру через `window.__sevGame`.
- Глобальные точки доступа: `window.__sevGame` (сцена, игрок, камера), `window.SevNPC` (жители), `window.__sevVehicleStore` (транспорт и монеты), `window.__sevRide`, `window.__grabState` (лассо).
- Параметры URL: `?debug` (FPS и `window.__sev`), `?tod=morning|day|evening|night`, `?drs=0`, `?joystick`.
- Локации: `pobedy` (Парк Победы, Омега и маяк — одна общая карта), `grafskaya` (откроется после охоты за сокровищами).
- Ресурсы лежат в `assets/` и подключаются относительными путями. `tools/build_single.py` собирает всё обратно в один HTML.
- Внутри ядра остаются закодированными в base64 (около 6 МБ): текстуры `__SEV_ASSETS`, миникарта `SEV_MINIMAP`, текстура суши `TX`. Код раскодирует их сам, поэтому для выноса в файлы нужна правка загрузки.

## Производительность
Подробно — в `docs/OPTIMIZATION.md`. Главное: в цикле кадра нельзя присваивать свойства, которые помечают материалы «грязными» (`imageProcessingConfiguration.*`, `scene.fogMode` и т. п.). Сейчас на кадр приходится 450 материалов и 8500 мешей, поэтому каждое такое присваивание обходится очень дорого.
