# Функции игры и их проверка — v177

Список собран по коду v176. Автотест: `tools/test/functest.py` (headless Chrome, экран 412×915). Каждый пункт с пометкой ✅ проверен одинаково на v176, на модульной версии и на v177: результаты совпали, ошибок JavaScript и HTTP нет.

## Проверено автоматически ✅
- Заставка, кнопка «Играть», карта Крыма → Севастополь → карта города
- Вход в Парк Победы, бухту Омега и к Херсонесскому маяку (общая карта района)
- Герой-лисёнок: ходьба (WASD), поворот, прыжок
- Жители: менеджер NPC, 21–25 жителей возле игрока, 5 квестов, подсказка «Поговорить»
- Лассо: кнопка 🪢 включает захват без ошибок
- Транспорт: покупка за монеты (самокат, детская машинка, машина, танк), посадка, езда, высадка
- Звуки: шаги и двигатель танка загружаются; аудиофайлы отдаются сервером без ошибок
- Время суток (ночь): картинка совпадает с v176
- Стрельба водой (кнопка 💥) — без ошибок

- Вертолёт (полёт, высота над землёй). Отдельного самолёта в коде не нашлось, только вертолёт
- Плавание, аквапарк, колесо обозрения
- Диалоги со всеми 22 жителями и цепочки квестов
- Магазин: одежда, причёски, глаза; эффекты самоката
- Охота за сокровищами, монеты (100 на локацию), сундуки городов-героев, «Летопись» Парка Победы
- Радио, музыка локаций, звуки на картах
- Погода (дождь, снег, ветер), смена времени суток в режиме «Авто»

- Живые улицы: машины, светофоры, пешеходы на проспектах
- 3D-карта Крыма с корабликами, перетаскивание кораблей
