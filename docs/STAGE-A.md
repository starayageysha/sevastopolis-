Источники аудиоконтекстов (создаются заново для каждой игры и не закрываются): `_tankAudioCtx`, `_waterAudio`, `_bumpAC` и сирена в постройке города — всё в `src/core/game.bundle.js`. Источник основной утечки нужно найти по снимку памяти — предлагаемая задача следующего этапа.
