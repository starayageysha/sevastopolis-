# Севастополис 3D

3D-игра в открытом мире по мотивам Севастополя: прогулки, квесты и тайники, жители-NPC, лассо, транспорт на суше, воде и в воздухе, смена времени суток и погоды, режим «Поиск» с камерой и GPS. Движок — Babylon.js 9.32, игра работает в браузере на телефоне и компьютере.

Автор идеи и создатель — Светлана Якимова (Telegram [@SvetlanaDonetsk](https://t.me/SvetlanaDonetsk)).

## Как запустить

Модульной версии нужен локальный веб-сервер: браузер не загружает модули и ресурсы с адресов `file://`. Подойдёт любой из вариантов:

```bash
npm run dev                        # если установлен Node.js → http://localhost:8080
python -m http.server 8080         # если установлен Python → http://localhost:8080
```

Чтобы видеть счётчик FPS и вызовов отрисовки, откройте `http://localhost:8080/?debug`.

Однофайловую версию (её можно открыть двойным щелчком или скопировать на телефон) собирает команда:

```bash
npm run build:single               # → dist/Sevastopolis-3D-single.html
```

## Структура

```
index.html               точка запуска: разметка и подключение модулей по порядку
src/core/game.bundle.js  ядро: Babylon.js + основной код игры (сцены, герой, транспорт, мир)
src/addons/NN-*.js       модули-дополнения, подключаются строго по номеру
src/data/NN-*.js         данные: модели героев, портреты, карта Крыма
```

## Правила разработки

1. Порядок `<script>` в `index.html` важен: модули обращаются к объектам, которые создают предыдущие.
2. Новую функцию лучше добавлять отдельным модулем в `src/addons` (следующий номер), а не править ядро.
3. `src/core/game.bundle.js` — уже собранный и сжатый код (исходников ядра в проекте нет). Править его можно, но точечно и с проверкой.
4. После любых изменений: `npm run test` (нужен запущенный `npm run dev` и Python с Playwright).
5. Каждая версия — отдельный коммит, номер версии (`vNNN`) в начале описания коммита.

## Публикация

Проект готов к статическому хостингу (Cloudflare Pages, GitHub Pages, любой сервер). Сборка не нужна: публикуется папка целиком, точка входа — `index.html`, заголовки для Cloudflare лежат в `_headers`. Все пути относительные, работают по HTTPS. Самый большой файл — 13,9 МБ, это укладывается в лимит Cloudflare Pages (25 МБ на файл). Однофайловая версия на 35 МБ в этот лимит бы не уложилась.

Игру выкладываем в открытый доступ только после проверки на телефоне и только с разрешения автора.
