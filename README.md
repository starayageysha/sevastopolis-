# Севастополис 3D

3D-игра в открытом мире по мотивам Севастополя: прогулки, квесты, тайники, коллекции, транспорт, живые улицы. Движок — Babylon.js, игра работает в браузере (Android и компьютер).

Автор идеи и создатель — Светлана Якимова (Telegram [@SvetlanaDonetsk](https://t.me/SvetlanaDonetsk)).

## Как запустить

Открыть `index.html` в браузере (Chrome на телефоне или компьютере). Всё нужное встроено в один файл.
